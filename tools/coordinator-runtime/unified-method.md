# Unified Reviews method closure

Actual Work can prospectively select `method_closure: "unified-definitions-v1"`
in a Reviews service policy alongside its exact `method` and `method_files` pins.
Compute the complete map with `reviews.method_files(entry,
"unified-definitions-v1", exclusions)`, supplying the actual opaque exclusions.
Validation and execution recompute that map with the runtime exclusions and
require exact equality. This selects source support, not deployment or acceptance.
Omitting `method_closure` retains the original traversal interpretation.

The compiler reads the exact absolute `unified-reviewer.prompt.md`, its linked
family and constituent definitions, and the common observation, semantics,
reuse and handoff contracts. Exact reference edges are recorded in
`coordinator_runtime/method_closure.py`: the unified method's alternate cohort,
conditionally selected recurrence/manual coordination, optional ecosystem
context, evaluation records and calibration references do not become ordinary
executable requirements. Public HTTP(S) citations are never local paths or
network acquisitions. Required definitions remain required; a missing one is a
provider dependency with its exact path, not permission to invent a file or
substitute an older method. A new unclassified local link is required and fails
closed outside the method home or for unsupported material. Changed meanings
of existing reference edges still require operator/provider interpretation;
mechanical closure does not prove that interpretation or method efficacy.

The compiler excludes private/hidden, runs, AGENTS and WORK_LOG paths before
metadata; rejects malformed URLs and absolute/escaping local paths; and acquires
only no-follow regular files, at most 128 files, 256KiB each and 1MiB total.
These are compiler acquisition bounds, separate from model-context allowances.
Fenced examples are not Markdown imports. No empirical archive, actual review
history, profile, provider runtime or missing-file alias is searched.

The current public provider check must be collected separately from runtime
qualification. Pin the whole required map and entry at the actual operator's
selection; reread current linked definitions when the provider changes. The
46-file closure encountered during correction482 included all nine families and
27 constituent definitions. That encounter is not a future pin, actual reviewer
invocation, coverage result, Source acceptance or rollout qualification.
