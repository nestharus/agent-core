Current-message control scope
=============================

The delegated control interpretation accounts for unfinished handling of the
whole current message and its actual dependencies. Governing constraints,
unrelated jobs, historical holds and another actor's observation remain binding
at their originals without becoming new assignments to this message. Unknown
current work, decisions, blockers or effects still prevent completion. Empty
lists, keywords and DONE alone establish no completion or clearance.

Genuine Work can read exact scalar pins with the existing supported CLI:

    coordinator processing-source CAPABILITY EVENT --plain-control-basis

The view checks current source selection, role authority, logical birth and
retained pins before body acquisition. It returns received birth, source hash,
logical source position, current classifier identity, original control/return
edge and exact queue metadata. Consumer payload_hash is its original event hash;
the disposal path independently checks the whole payload against that hash and
the immutable return. This view is not an eligibility or acceptance receipt.

Use the existing processing-dispose-plain-control typed receipt only after a
genuine whole-source/result/queue/descendant/effect/authority interpretation.
An unreserved Work return may also be awaiting-owner/@unresolved in control
phase, with its own successful collected classifier under the current capability.
The Work receipt still accounts losslessly for every old obligation, including
exact owner/source evidence or the existing bounded current Work attestation.
No old result or six-entry history is rewritten. Original ACK classifier lineage
and later current classification are distinct. No receipt resolves real work,
reservation, hold, pending descendants, outbox, publication or effect uncertainty.
The old274 native lookup guard remains unchanged and deferred.

The source-only qualification runner uses one fresh .qualification862 namespace,
immutable Git-blob exports, read-only source/SDK/fixtures, private TMPDIR before
imports and network isolation. Its explicit fixture-plan.json precedes children.
Synthetic actors and collected answers exercise production entrypoints; they
cannot qualify actual provider interpretation or eventual live control behavior.
Keep all owned fixtures, failed oracles and collection limits for Work disposition.
