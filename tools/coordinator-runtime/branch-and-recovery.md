## Original collector and review recovery

   service, attempts, jobs and contexts.
2. `recover-service CAP ORIGINAL_CONTROLLER --receipt FILE` takes exactly `basis,
   activity, actual_END, evidence, remaining_holds, custodians`. Activity is

   capability only for the same genuine issuer, unchanged original configuration
   and a revoked predecessor; old authority is never reactivated. The old process/child records and unknowns remain
   unchanged. No handle is adopted, no foreign child is waited, no effect is
   cleared. Real conflicting capacity/resources remain held; independent eligible
   work progresses. No lifetime-start reset or entitlement inflation occurs.
