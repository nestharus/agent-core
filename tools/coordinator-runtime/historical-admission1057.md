# Historical dependencies in current admission

This source-only feature extends the existing held-phase resource comparator.
It grants no old execution, input, closure, physical guarantee or acceptance.
The original1041 diagnostic remains a subset diagnostic.

Two actual current principals independently delegate exact fields in the existing
historical_metadata_access table. Work's original authenticated journal issuer
selects work-journal fields and its software executor ceiling. The original
Reviews Source custodian selects reviews-source fields and the authorized reader
ceiling, naming the Work access key. Current session checks, the original stopped
journal/grant binding, exact source visibility and source/configuration pins are
required. A role title or possession of a key supplies no delegation.

Use historical-resource-authorize --domain work-journal --selection FILE as the
actual Work principal, then the same command with --domain reviews-source as the
actual Reviews principal. Selections contain identity, purpose, authority,
expires (within one hour), principal (current Work), configuration, implementation,
fields and ceiling. Work additionally supplies preserved_bytes: its genuine
preserved allocation bound, without reading old captures to obtain it. Reviews
additionally supplies work_access. Exact fields are defined by
historical_admission.FIELDS. Each ceiling contains mode, reads, writes, unbounded.
Only mode=cooperative-authorized-ceilings and unbounded=false are supported.
Reviews' ceiling must be read-only. Every operand is independently public and
permitted before any acquisition; unmatched old paths are never exported.

Use historical-resource-project --selection FILE as current Work. FILE is the
two-key object {"work-journal": UUID, "reviews-source": UUID}. It verifies the
original frozen task/configuration/transition/proof/epoch/birth and original
call/context/collector, without demanding today's capability for that old row.
It also requires full original declared read coverage and bounded public material
coverage. Public subset disjointness cannot pass this complete-ceiling path.
The Work executor ceiling must include original attempt staging and the retained
review-inputs/review-handles/review-history namespaces. Every pending history and
publication target/temporary remains a write; additional attempts or opaque
ordinary/routine obligations refuse. No native handle/run/session is inspected.
